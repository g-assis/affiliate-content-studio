# Decisões

- Público inicial: afiliados iniciantes que aparecem nos próprios vídeos.
- UX: três etapas, poucas configurações, português brasileiro.
- Storyboard: SVG de bonecos de palito; sem vídeo generativo.
- Primeiro deploy: Next.js na Vercel, sem backend separado até ser necessário.
- Links reais não são processados neste marco; dados mockados explicitamente.
- Transparência: sinalizar publicidade e links de afiliado.
- Custo inicial: evitar serviços pagos.
